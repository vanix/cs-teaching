# 計算機概論教學網站

透過遊戲快樂學習計算機概論！包含二進位、進位換算、摩斯電碼等互動學習遊戲。

## 遊戲列表

| 單元 | 遊戲 | 說明 |
|------|------|------|
| 一 | 二進位點數卡片遊戲 | 翻牌湊出 0～31 的數字，練習二進位表示法 |
| 二 | 進位解密大作戰 | 2 進位轉 8 / 16 進位，用點數卡片理解進位換算 |
| 三 | 摩斯二進位電報解碼戰 | 聽音解碼或發射電報，用摩斯聲音對照二進位卡片解碼 |
| 四 | 摩斯二進位字母解碼戰 | 用摩斯聲音對應 A～Z 字母，包含聽音與單字解碼關卡 |
| 五 | 亂碼解碼實驗室 | 自訂編碼表，體驗編碼不匹配時產生亂碼的原理 |

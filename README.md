# 計算機概論教學網站

透過遊戲快樂學習計算機概論！包含二進位、進位換算、摩斯電碼等互動學習遊戲。

## 遊戲列表

| 單元 | 遊戲 | 說明 |
|------|------|------|
| 一 | 二進位點數卡片遊戲 | 翻牌湊出 0～31 的數字，練習二進位表示法 |
| 二 | 進位解密大作戰 | 2 進位轉 8 / 16 進位，用點數卡片理解進位換算 |
| 三 | 二進位邏輯運算大冒險 | 學習 AND、OR、NOT、XOR 等位元邏輯運算 |
| 四 | 容量特工 | 學習 Byte、KB、MB、GB、TB 等電腦容量單位換算 |
| 五 | 摩斯二進位字母解碼戰 | 用摩斯聲音對應 A～Z 字母，包含聽音與單字解碼關卡 |
| 六 | 亂碼解碼實驗室 | 自訂編碼表，體驗編碼不匹配時產生亂碼的原理 |
| 七 | 像素塗鴉：製作 Discord Emoji | 在 8x8 點陣上創造像素圖，理解位元與影像儲存 |
| 八 | 認識點陣圖、向量圖與字體 | 比較點陣圖與向量圖的差異，認識字體結構與點陣字、向量字原理 |
| 九 | 影片檔案大小計算 | 理解影片由連續畫面組成，解析度、幀率與色彩位元如何影響檔案大小 |
| 十 | 聲波取樣與量化實驗室 | 了解取樣率與量化位元深度，理解類比轉數位 |
| 十一 | 電腦五大單元跟匯流排 | 認識輸入、輸出、記憶、算術邏輯、控制五大單元與訊號流向 |
| 十二 | 主機組裝模擬器 | 在真實主機板上依序安裝 CPU、記憶體、顯示卡等零件 |
| 十三 | 主機板 I/O 連接埠配對 | 配對各種 I/O 連接埠與周邊裝置，認識主機板後方面板 |
| 十四 | CPU 核心原理與效能指標 | 認識 CPU 時脈頻率、機械週期與 MIPS 效能指標 |
| 十五 | 內儲程式與記憶體特性 | 學習內儲程式概念、記憶體分類特性，比較 HDD 與 SSD 差異 |
